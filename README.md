# DAMATH Tournament Manager — Releases

Downloads for **DAMATH Tournament Manager**, a Windows app for running DAMATH tournaments: player
registration, Round Robin and Swiss pairings, results, standings with the official tie-breaks, a
projector-ready presentation screen, and printable sheets. Works fully offline.

**Developer:** GENESES C. ABARCAR

## Download

Get the latest installer from the **[Releases](https://github.com/EduFilesPH/damath-tournament-manager-releases/releases/latest)**
page: download `DAMATH-Tournament-Manager-Setup-<version>.exe` and run it.

Windows may show a SmartScreen notice because the installer is not code-signed. Choose
**More info → Run anyway** to continue.

## Updates

Once installed, the app keeps itself up to date. It checks this page for new versions, downloads them in
the background, and installs them the next time you close the app (or right away with
**Restart & update**). **Help → About** shows your version and lets you check for updates manually.
